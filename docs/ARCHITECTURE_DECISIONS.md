# VMADX Development Decisions

1. VMADX is an independent product and codebase.
2. Existing projects are reference sources only.
3. ADX is the only initial strategy.
4. Kotak Neo is the only initial broker.
5. Paper trading must be implemented and validated first.
6. Live trading remains disabled by default.
7. Database changes must use migrations.
8. Secrets must never be committed to Git.
